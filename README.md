# Application React - Agence d'Assurance

Application frontend moderne permettant de:

- sélectionner un type de demande
- remplir un formulaire dynamique
- prévisualiser le document
- générer et télécharger un PDF

## Stack

- React (hooks)
- React Router
- Tailwind CSS
- React Hook Form
- jsPDF

## Lancer le projet

```bash
npm install
npm run dev
```

## Build de production

```bash
npm run build
```

## Types de demandes pris en charge

- Résiliation
- Résiliation + Ristourne
- Changement de fraction
- Diminution de garantie
- Extension de garantie

## Bonus inclus

- Sauvegarde automatique des données du formulaire dans `localStorage`
- Option d'impression depuis la prévisualisation
